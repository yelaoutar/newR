# Gestion des étudiants

## Description

Application Python qui calcule la moyenne et le résultat des étudiants.

## Technologies

Python 3, Pytest, Git et GitHub.

## Installation sous Windows

```powershell
git clone https://github.com/yelaoutar/newR.git gestion_etudiants
cd gestion_etudiants
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Sous Linux, activez l'environnement avec `source venv/bin/activate`.

## Exécution et tests

```powershell
python src/main.py
python -m pytest -v
```
